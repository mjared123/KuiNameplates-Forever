# ForeverPlates

Clean, minimal nameplates for WoW: Forever: thin flat bars, the name above the bar, level and health inside it.

## Install
Copy the `ForeverPlates` folder into `World of Warcraft/_classic_era_/Interface/AddOns/` (or the AddOns folder of your WoW: Forever install) and restart the game.

## Features
- Reaction-coloured health bars, class colours for enemy players
- Level with elite/rare markers, health percent when damaged
- White outline on your target, faded non-target plates
- Threat glow (orange: you're near the top of the threat table, red: you have aggro), optional tank mode colouring
- Raid target icons
- `/fp range <yards>` to raise the max nameplate distance

## Commands
`/fp` lists all commands.
